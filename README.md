# Nalanda Concept School Website

An interactive, responsive official website for **Nalanda Concept School (SD Education)**, specializing in primary schooling (Classes I to VI) and foundational preparation for competitive entrance exams such as Navodaya, Netarhat, Simultala, R.K. Mission, and Sainik School.

---

## 🌟 Key Features

* **Responsive Navigation Header:** Clean desktop menu that adapts into a collapsible mobile drawer for screen widths under 720px.
* **Top Announcement Bar:** Prominent banner highlighting active admissions and target classes.
* **Dynamic Campus Gallery:** Automated auto-sliding photo carousel with manual dot controls (4-second interval).
* **Leadership & Guiding Vision:** Vintage parchment-style cards showcasing the Principal's message and Co-Founder's vision with custom framed photos.
* **Comprehensive Footer:**
  * Quick links to admissions, photo/video archives, and fee payment.
  * Program listings for competitive wings and campus facilities.
  * Embedded Google Map targeting the Rajgir Bypass Road campus.
  * Office visiting hours, contact details, and social channels.
